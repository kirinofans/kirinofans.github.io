[Paper Reading] A Style is Worth One Code: Unlocking Code-to-Style Image Generation with Discrete Style Space

[Paper Notes] CoTyle: Code-to-Style Image Generation with Discrete Style Codes

paper: CoTyle
Subjects: Computer Vision and Pattern Recognition (cs.CV)

Abstract

The exploration of aesthetically or artistically engaging styles in text-to-image generation presently involves a stochastic search across a vast code space. Existing methods either rely on textual prompts (which exhibit poor stylistic consistency) or leverage reference images / pre-trained style LoRAs (which lack creativity and cannot produce novel styles). This paper proposes CoTyle, the first open-source framework for code-to-style image generation, where a numerical style code is used to create novel visual styles. The core idea is to design an autoregressive style generator that produces discrete style indices to guide a text-to-image diffusion model in generating images with a specific style. CoTyle additionally supports image-conditioned generation and style interpolation. Experiments demonstrate that discrete codes can generate diverse visual styles while faithfully following input text prompts.

1. Research Background & Motivation

1.1 Motivation

Stylistic image generation is a fundamental task in creative content production. However, existing approaches suffer from significant limitations:

  1. Textual prompt-based methods usually exhibit poor stylistic consistency — specifying a style through text alone (e.g., “in the style of Van Gogh”) often produces inconsistent or weak stylistic effects across different prompts.

  2. Reference-based methods either leverage the style of a reference image as the style definition, or insert a pre-trained style LoRA into the generative model to enable specific style generation. While these approaches can achieve strong style fidelity, they suffer from poor creativity — they can only reproduce existing styles and cannot create novel ones.

Core Insight: The paper argues that style information should not be narrowly defined as color, but encompasses rich semantic features. Unlike traditional style transfer methods, CoTyle treats style as a structured, discrete representation that can be generated, manipulated, and interpolated.

1.2 Core Challenge

The fundamental challenge is: how to define a compact, discrete style representation that (1) captures rich stylistic information beyond mere color, (2) can be autoregressively generated to produce novel styles, and (3) can be effectively injected into a diffusion model without compromising text-image alignment.

2. Related Work

2.1 Conditioned Image Generation

Common conditioning mechanisms in diffusion-based generation include:

  1. Noise Inversion: DDIM Inversion, Null-text Inversion — invert a real image back to noise space and use it as a starting point for editing.
  2. Adapter Modules: T2I-Adapter, IP-Adapter, ControlLoRA — lightweight plug-in modules that inject spatial or semantic conditions into the diffusion model.
  3. Parameter-Efficient Fine-Tuning: LoRA-based approaches that adapt model weights for specific tasks.
  4. Token Concatenation: Textual Inversion — learn new text tokens that represent specific concepts or styles.

2.2 Stylistic Image Generation

Existing stylistic generation approaches fall into two categories:

  • Style image as visual condition: Certain approaches employ style images as visual conditions, injecting style information through the visual branch of the model.
  • Style LoRA training: Others train style-specific LoRA modules to enable particular style generation.

Key limitation: Both categories lack the capability to create novel styles — they can only reproduce styles seen during training or provided as reference.

3. Method Architecture

3.1 Overview

The core idea of CoTyle is to design an autoregressive style generator that produces style indices to guide the text-to-image diffusion model (T2I-DM) in generating images with a specific style. The framework consists of three main components:

  1. Style Codebook & Image Reference Model (training)
  2. Style Generator (training)
  3. Inference Pipeline (generation)

3.2 (a) Training Style Codebook and Image Reference Model

The first step is to build a discrete style codebook through Vector Quantization:

  • For a given image, extract its ViT feature vvv;
  • Apply vector quantization to obtain corresponding discrete indices from the style codebook;
  • Each index maps to a learned style vector that captures rich stylistic information.

Codebook specifications:

  • Codebook size: K=1024K = 1024K=1024
  • Each index maps to one 64-dimensional style vector
  • Length of style index sequence: N=196N = 196N=196

This means each image’s style is represented as a sequence of 196 discrete tokens, each selecting one of 1024 possible style vectors.

3.3 (b) Training Style Generator

The discrete indices obtained from the codebook are then used to train an autoregressive model via next token prediction, effectively learning the distribution of style features.

Inference process:

  • Use the input number as the random seed → output start index;
  • The model outputs the probability distribution of all 1024 indices for the next position;
  • Repeat autoregressively to generate the full sequence of 196 style indices.

All 196 vectors are then concatenated to form the full style embedding, which is injected into the diffusion model.

3.4 © Inference: DiT Diffusion Generation

The concatenated style embedding is injected into the DiT (Diffusion Transformer) to guide the generation of the final image. A key design choice is injecting style through the textual branch rather than the visual branch.

Why textual branch? As shown in Figure 5, injecting style from the textual branch better preserves semantic information compared to the visual branch approach used by existing methods. This ensures that the generated image faithfully follows the input text prompt while simultaneously exhibiting the specified style.

3.5 Style Code Analysis: High-Frequency vs. Low-Frequency Indices

An interesting finding from the analysis (Figure 7) is that outputs guided purely by high-frequency indices resemble vanilla T2I outputs and carry no distinct style. This suggests that stylistic information is primarily encoded in the low-frequency (less common) indices of the codebook, while high-frequency indices capture generic, style-agnostic features.

4. Experimental Results

4.1 Qualitative Comparison

Figure 6 shows qualitative comparisons demonstrating that CoTyle is not only capable of generation conditioned on style codes but also supports style images as input. The model can faithfully follow the input text while simultaneously generating the specified style.

4.2 Three Generation Modes

CoTyle supports three distinct modes of style exploration:

  1. Random: Use a random numerical code as input to generate a completely novel style. This enables exploration of the vast style space without any reference.
  2. Image-conditioned: Given a style reference image, extract its style code and use it to guide generation. This allows faithful reproduction of existing styles.
  3. Style Interpolation: Interpolate between two or more style codes to create smooth transitions and hybrid styles, enabling fine-grained style control.


5. Conclusion & Future Work

5.1 Contributions

  1. Propose the new task: code-to-style image generation — using numerical style codes to create novel visual styles.
  2. Propose CoTyle: the first open-source framework combining a style generator with a diffusion model for this task.
  3. Two extra features: image-conditioned generation and style interpolation, providing flexible style control.
  4. Experiments prove that discrete codes can generate diverse visual styles while maintaining text-image alignment.

5.2 Future Work

Potential directions include:

  • Exploring finer-grained style control through hierarchical codebook designs;
  • Extending the framework to video generation for temporally consistent stylistic content;
  • Investigating user-interactive style exploration interfaces.
