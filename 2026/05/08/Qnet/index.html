[论文笔记] DQnet: Cross-Model Detail Querying for Camouflaged Object Detection

paper: DQnet: Cross-Model Detail Querying for Camouflaged Object Detection
Subjects: Computer Vision and Pattern Recognition (cs.CV)

摘要

伪装目标检测（COD）的核心难点在于消除目标物体与背景之间高内在相似性所引发的歧义。现有方法存在明显局限：基于 CNN 的方法受限于局部感受野导致漏检或误激活背景；基于 ViT 的方法虽能捕获全局特征，但会冲刷掉边缘纹理等低层细节，且在 COD 场景下加剧目标-背景混淆。本文提出首个跨模型 COD 框架 DQnet，包含双分支特征提取与核心的 RBQ（基于关系的查询）模块。RBQ 以 ViT 的全局语义作为查询（Q），去查询 ResNet 的局部细节（K/V），并配套设计了**显著性感知损失（SAL）**提升细节查询效果。该方法在 CHAMELEON、CAMO、COD10K、NC4K 四个主流数据集上大幅超越现有最优模型。

1. 研究背景与挑战

1.1 伪装目标检测概述

  • 自然场景：动物通过体色、形状、纹理伪装自己以躲避天敌（如野生动物摄影）。
  • 人工场景：军事伪装等。
  • 应用价值：医学图像分析（息肉分割、肺部感染分割）、图像合成、艺术创作等。

1.2 COD 的核心问题

COD 的核心问题是如何消除目标物体与背景之间高内在相似性所引发的歧义，这就要求学习到的表征能够精准激活物体的完整范围。

1.3 现有方法的两大缺陷

  1. 基于 CNN 的 COD 方法：
    • 卷积是局部感受野，只能看图片一小块，抓不到远距离特征关联。
    • 结果：只激活目标局部、甚至误激活背景，出现漏检/冗余区域。之前的改进未从根本解决 CNN 的局部缺陷。
  2. 基于 ViT 的方法：
    • 虽能抓全局特征，但直接用在 COD 有两个致命问题：
      • ViT 的 MLP 层全局矩阵乘法，会冲刷掉边缘、纹理等低层细节。
      • COD 中目标和背景的图像块太像，ViT 会加剧目标-背景混淆。

1.4 本文核心贡献

  1. 提出首个跨模型 COD 框架 DQnet，同时捕获全局语义并且注重细节。
  2. 发明 RBQ 模块融合跨模型特征，并设计显著性感知损失（SAL）提升细节查询效果。
  3. 在 4 个主流 COD 数据集（CHAMELEON、CAMO、COD10K、NC4K）上大幅超越现有最优模型。

2. 相关工作

2.1 纯 CNN 主导的 COD 方法

所有方法都基于 ResNet、VGG 等卷积网络，例如 ANet-SRM、SINet、ZoomNet、BGNet 等。

2.2 纯 Transformer 主导的 COD 方法

用 Transformer 的全局能力解决 CNN 的局部问题，但直接用 Transformer 做特征提取，忽略了它丢失细节的缺陷，如 OSFormer 等。

2.3 CNN+Transformer 简单融合方法

这类方法试图结合两者的优点，但融合方式粗暴，没有解决跨模型语义的问题，效果提升有限：

  • TransUNet 类方法：先用 CNN 提取局部特征，再把特征转成 token，用 Transformer 编码全局上下文，最后解码分割。
  • 双编码器方法：并行用 CNN 和分层 Transformer 提取特征，然后简单相加或拼接。
  • 固有问题：没有交互机制，没有真正融合。

3. 方法架构


DQnet 是一个双分支 + 跨模型查询的伪装目标检测框架：

  • 双分支特征提取：CNN 分支提取局部细节；Transformer 分支提取全局信息。
  • RBQ 模块：跨模型查询，融合全局 + 局部特征。
  • 轻量级解码器：融合增强特征，输出最终分割结果。

3.1 RBQ 核心查询模块（网络的心脏）

  • 查询 Q：ViT 输出的全局语义 token（Global Cues）。
  • 键 K / 值 V：对齐后的 ResNet 局部 token（Local Details）。
  • 查询机制：把 Q 和 K/V 都切成 4×4 的小窗口。在每个窗口内，计算全局 Q 和局部 K 的相似度：相似度越高，说明这个局部细节越可能是目标的一部分。按相似度加权融合 V，得到只包含目标关键细节的增强特征（Crucial Details）。
  • 效果：对比 ResNet 原始特征和增强后的特征，可以明显看到目标区域（如猫头鹰）被高亮，背景噪声被抑制。

3.2 双分支特征流与对齐

  • ViT 分支：图像分块（本文为 16×16），加上“位置标签”后经过 12 层 Transformer 自注意力计算，输出全局语义 token，作为唯一的查询源去 ResNet 的每个尺度查询细节。
  • ResNet 分支（Rblock 层）：输出有两个去向：去向 1 送入 Alignment 模块和 ViT 特征融合；去向 2 送入下一个 Rblock 提取更高级的特征。

    严格的跨模型公式约束：

Qw,fi=ZwiWqiQ_{w,f}^i = Z_w^i W_q^i Qw,fi​=Zwi​Wqi​

Kw,fi=YwiWki,Vw,fi=YwiWviK_{w,f}^i = Y_w^i W_k^i, \quad V_{w,f}^i = Y_w^i W_v^i Kw,fi​=Ywi​Wki​,Vw,fi​=Ywi​Wvi​

  • ZwiZ_w^iZwi​（第 iii 个窗口的 ViT 特征）只能用来生成 Q。
  • YwiY_w^iYwi​（第 iii 个窗口的 ResNet 特征）只能用来生成 K/V，不能生成 Q。
  • 物理意义：ViT 用以定位目标的位置，ResNet 提取目标的细节，以至于细节会被加权放大。

3.3 计算复杂度分析

借助基于窗口的注意力机制，计算复杂度降至与输入规模呈线性关系。RBQ 模块针对每张图像的计算复杂度为 O(w2HWC)O(w^{2} H W C)O(w2HWC)，而全局注意力的计算复杂度为 O((HW)2C)O((H W)^{2} C)O((HW)2C)，这使得细节查询更加高效。

3.4 损失函数设计

  1. 加权二元交叉熵损失 LBCEwL_{BCE}^wLBCEw​：
    COD 任务中，90% 以上的像素都是容易区分的背景，只有不到 10% 的像素是难分的目标边缘、遮挡区域和与背景高度相似的区域。论文采用边界感知加权 BCE（引自 F3Net，COD 领域通用基础损失），给每个像素分配不同的权重。
  2. 加权 IoU 损失 LIoUw\mathcal{L}_{IoU}^wLIoUw​：
    考虑像素之间的空间关系。IoU（交并比）损失关注的是预测区域和真值区域的整体重叠度。
  3. 显著性感知损失 LSAL\mathcal{L}_{SAL}LSAL​（核心创新）：
    专门为 RBQ 细节查询模块设计的损失，之前的所有 COD 损失都无法有效监督“跨模型细节查询”这个过程。
    • 核心发现：RBQ 输出的增强特征中，目标的关键区域的特征值会显著高于背景区域。RBQ 模块自己要能识别出哪些细节是重要的。
    • 计算方式：分子为“加权后的总损失”（4 个尺度的所有像素，每一项是该像素的最终权重 × 该像素的基础 BCE 损失）；分母为“所有像素的权重总和”。

4. 实验结果分析

4.1 评价指标

采用四种广泛使用的指标进行全面评估：

  • 结构度量（S-measure）：计算预测图与真实值之间的目标感知和区域感知结构相似性，重点评估结构信息。
  • E-度量（E-measure）：基于人类视觉感知机制，评估显著目标检测结果的整体和局部准确率。
  • 加权 F-度量（Weighted F-measure）：对预测图精确率和召回率的综合衡量。
  • 平均绝对误差（MAE）：用于衡量前景-背景分割误差。

4.2 消融实验

  1. 核心模块验证：验证 RBQ 和 SAL 这两个核心创新对性能的提升。
  2. 融合方式对比：验证 RBQ 融合方式比简单相加/拼接更优。对比了直接相加、相乘、拼接、RBQ 窗口注意力，结论是 RBQ 全面碾压简单融合。
  3. 注入层验证：验证 RBQ 加在 ResNet 哪些层效果最好。
  4. 窗口大小验证：验证 RBQ 窗口大小选多少最优。结论是 窗口 = 4 最优，完美平衡了速度和精度。

4.3 可视化分析


多尺度细节查询的可视化结果清晰展示了流程：(a) 输入图像 -> (b) ViT 注意力图 -> © 最后三个阶段的普通 ResNet 特征 -> (d) RBQ 增强后的 ResNet 特征 -> (e) 分割结果与真实标签。可以看出 RBQ 极大增强了目标的边缘与内部细节。

5. 结论

5.1 结论

本文提出了跨模型细节查询网络 DQnet 用于伪装目标检测（COD）。通过设计 RBQ（基于关系的查询）模块，能精准提取 COD 任务所需的关键细节，充分结合了 Transformer 长距离依赖建模/目标整体定位与 CNN 细粒度细节提取的双重优势，同时有效过滤了背景噪声。在 4 个主流 COD 基准数据集上的实验证明，DQnet 大幅提升了伪装目标检测的性能。
