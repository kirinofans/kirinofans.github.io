[论文笔记] CleanDIFT：无噪声的扩散特征提取

paper: CleanDIFT: Diffusion Features without Noise
Subjects: Computer Vision and Pattern Recognition (cs.CV)

摘要

大规模预训练扩散模型的内部特征，已成为适配多种下游任务的强力语义描述工具。现有使用扩散特征的工作通常需要先给图像添加噪声，再输入模型提取语义特征——因为当输入图像噪声极低甚至无噪声时，扩散模型无法输出最具效用的特征。本文证实，输入噪声会对特征的可用性产生严重负面影响，且该问题无法通过不同随机噪声的集成策略解决。针对这一问题，本文提出CleanDIFT，一种轻量级无监督微调方法，使扩散骨干网络能够输出高质量的无噪声语义特征。在多种提取设置与下游任务中，该特征的性能均大幅超越传统扩散特征，效果甚至优于基于集成的方法，而计算成本仅为其一小部分。

1. 研究背景与挑战

1.1 研究背景

扩散模型可通过自监督方式完成大规模训练，在图像、视频生成领域达到业界领先水平。其内部特征近年来被广泛用作语义描述子，在零样本、微调场景下均能实现优异的下游任务表现。

传统扩散特征的提取流程为：先给干净图像添加指定程度的噪声，再输入扩散模型的U-Net结构，从解码器的指定中间层抽取特征。

1.2 Motivation 与核心难点

（1）噪声损害特征质量

要提取有效特征必须先给输入加噪，但噪声会直接损失原图信息。论文通过实验证实，即便是常用的中等噪声步，提取的特征中也有相当一部分方差完全来自输入噪声，属于无效干扰；且仅靠多次随机噪声集成，无法根除这一问题。

（2）时间步依赖

不同下游任务需要不同的最优时间步ttt（语义对应任务用\(t=261\)，分割任务用\(t=100\)，低层次任务用\(t=50\)），需要逐任务调参。部分方法通过多噪声集成缓解该问题（如DIFT平均8次采样），但计算开销成倍增加。

上述问题的本质是：扩散模型在不同噪声水平下学到了不同语义层次的信息——高噪声对应粗结构，低噪声对应精细细节。这一特性提供了多尺度特征，但也造成了严重的时间步依赖。

1.3 本文目标与核心贡献

本文目标是：从扩散模型中提取无噪声、时间步无关的通用语义特征，同时保留甚至超越有噪声、多时间步特征的性能。

核心贡献分为两点：

  1. 提出CleanDIFT，一种针对扩散模型的微调方法，可使扩散模型直接处理干净图像，让模型固有的世界知识更易获取。
  2. 实现将所有扩散时间步的信息整合到单一特征预测中，从而无需针对下游任务进行时间步调优。

2. 相关工作

自监督视觉表征学习

大规模预训练基座模型的内部特征，在零样本、微调场景下均可达到媲美监督模型的效果。三类典型预训练范式包括：

  • 掩码重建类：以MAE为代表，通过重建图像遮挡区域学习表征
  • 对比学习类：以CLIP为代表，通过图文对对比学习跨模态语义
  • 自蒸馏类：以DINOv2为代表，通过判别式目标+自蒸馏学习通用视觉特征

扩散特征的退化


由于现有方法需要将含噪图像输入模型以获取有效特征，这会显著减少模型可提取的感知信息，原图细节被噪声破坏。本文通过提取无噪有效特征来缓解这一问题，从而提升下游任务的性能。

3. 方法架构

3.1 传统扩散特征提取与噪声问题

3.1.1 扩散前向加噪基础

扩散模型的标准前向加噪过程为：

xt=αtx0+1−αtϵx_t = \sqrt{\alpha_t} x_0 + \sqrt{1-\alpha_t}\epsilon xt​=αt​​x0​+1−αt​​ϵ

其中αt\alpha_tαt​是与时间步相关的系数，ϵ\epsilonϵ为随机高斯噪声。

3.1.2 传统扩散特征提取

传统扩散特征的提取流程为：

  1. 按时间步ttt给干净图像加噪，得到带噪图像xtx_txt​
  2. 将xtx_txt​和时间步ttt输入U-Net去噪网络
  3. 从U-Net解码器的人工选定位置，抽取中间层特征图

该方式存在两大固有缺陷：

  • 加噪操作会瓶颈化模型可提取的感知信息，原图细节被噪声破坏
  • 不同下游任务最优时间步不同，需要逐任务调参

3.1.3 扩散特征编码噪声的验证


为量化噪声对特征的影响，论文设计了验证实验：

  • 分别将纯噪声、干净图像、带噪图像输入扩散模型，提取对应特征
  • 用最小二乘法拟合标量系数，用纯噪声的特征去拟合带噪图像的特征
  • 计算拟合结果能解释带噪特征多大比例的方差

核心结论：

  • 即使是常用的中等时间步\(t=261\)，纯噪声也能解释特征中相当大比例的方差，说明传统扩散特征里混入了大量无效噪声信息
  • 干净图像的特征也无法完全解释带噪特征的剩余方差，中等时间步的特征存在大量时间步专属的成分

3.2 CleanDIFT：无噪声扩散特征


整体框架采用师生架构：以预训练扩散模型（SD 1.5/2.1）为教师，初始化一个可训练副本作为学生特征提取器。学生接收干净图像（无噪声、无时间步输入），教师接收对应的加噪图像和时间步。在11个特征提取位置，通过时间步条件投影头将学生特征投影到教师特征空间，最大化余弦相似度。训练仅需400步/30分钟，推理时丢弃投影头，直接使用学生模型的内部特征。

模块1：冻结教师模型（原始预训练扩散模型）

  • 原始Stable Diffusion的U-Net，权重全程冻结
  • 输入：带噪图像xtx_txt​ + 对应时间步ttt + 文本条件
  • 正常执行一次前向传播，输出U-Net中11个指定位置的中间层特征图feat(k)(xt;t)feat^{(k)}(x_t; t)feat(k)(xt​;t)（\(k=1\)到111111）
  • 这11层包括：U-Net最中间的瓶颈块，以及除最后两块外的所有解码器块
  • 不同层特征特性不同：浅层对应边缘、纹理等底层信息，深层对应物体、类别等高层语义

模块2：可训练学生模型（CleanDIFT特征提取器）

  • 与教师模型的完整权重副本
  • 输入只有干净图像x0x_0x0​，并且不输入时间步ttt
  • 执行U-Net前向传播，输出对应位置的11层干净特征图

不输入时间步的原因：最终目标是得到一套通用于所有任务的特征，因此训练阶段就要产出统一的特征表示，使其能够适配所有时间步的知识。

模块3：时间步条件投影头（Projection Heads）

  • 附加的可训练模块，只在训练时使用，推理时弃用
  • 输入：学生模型输出的某一层干净特征 + 当前要对齐的时间步ttt
  • 结构：每一层特征对应一个独立的投影头，由3层前馈网络（FFN）堆叠而成；采用零初始化 + 残差连接
  • 作用：对学生的统一干净特征做逐点变换，把它对齐到当前时间步下教师特征的分布空间
  • 输出：投影后的特征图proj(k)(featc(k)(x0);t)proj^{(k)}(feat_c^{(k)}(x_0); t)proj(k)(featc(k)​(x0​);t)，尺寸、通道数和教师对应层特征完全一致

不同时间步的扩散特征具有不同语义特性，投影头将学生的统一特征分别映射到各时间步空间，迫使学生特征包含所有时间步的信息。

3.2.2 损失函数计算

核心目标：投影后的学生特征，和对应时间步的教师特征越相似越好。

完整计算流程：

  1. 输入一张干净图像x0x_0x0​，采样得到III个时间步
  2. 对每个采样的时间步tit_iti​，给干净图像加上对应强度的噪声，生成带噪图xtix_{t_i}xti​​
  3. 把干净图像输入学生模型，得到11层干净特征
  4. 把每张带噪图 + 对应时间步输入教师模型，得到III组、每组11层的教师特征
  5. 对每个时间步、每一层特征，用对应的投影头，把学生特征转换成带时间步的版本
  6. 计算投影后学生特征和教师特征的余弦相似度
  7. 将11层、所有时间步的相似度全部累加，取负数，得到总损失

3.2.3 分层时间步采样策略

单张训练图像、最大时间步\(T=1000\)、分层数\(I=3\)，具体步骤：

  1. 把0~1000的时间步范围，均匀分成3个区间：低噪声、中噪声、高噪声
  2. 每个区间里随机采样1个时间步
  3. 这3个时间步每个都算一次损失，累加起来共同更新权重

分层采样保证每张训练图，都同时覆盖低、中、高三个噪声等级。

推理阶段：把干净图像输入训练好的CleanDIFT学生模型，执行一次前向传播，即可输出11层无噪声、时间步无关的通用特征图，直接用于下游任务。

4. 实验结果分析

4.1 语义对应匹配


在语义对应任务上，干净特征相比基础扩散模型，错误匹配的数量显著更少。

  • 标准扩散特征（带噪输入）的PCK（正确关键点百分比）性能随时间步变化，存在最优峰值
  • CleanDIFT的性能是一条水平直线，完全不依赖时间步，并且全程高于标准扩散特征的最优峰值
  • 定量结果：SD 2.1基线最优PCK_img为59.61，CleanDIFT达到61.43，相对提升1.82

4.2 深度估计


从定性结果来看，CleanDIFT预测的深度图噪声明显更少，边缘和结构更清晰、更贴近真值。

4.3 语义分割


基于Pascal VOC数据集的语义分割任务：

  • 定性结果：标准SD特征以\(t=100\)作为时间步（该时间步定量表现最佳），CleanDIFT的分割图相比标准扩散特征的分割图，噪声显著更少。
  • 定量结果：SD 2.1最优mIoU为20.81，CleanDIFT达到21.24，相对提升0.43。标准扩散模型的性能很大程度上取决于最佳噪声步长ttt的取值，而CleanDIFT无需调参即可达到更优效果。

4.4 消融实验

以DIFT为基础框架、在SPair-71k测试子集上做消融，验证每一项设计选择的合理性。

1. 损失函数的选择

对比L1损失、L2损失、余弦相似度三种对齐目标：

  • 三种损失训练出的模型，性能都优于原生SD 2.1基线
  • 余弦相似度效果显著最优，大幅领先L1、L2

2. 投影头的作用

对比「有投影头」和「无投影头」两种设置，搭配三种损失分别测试：

  • 在主配置（余弦相似度）下，加入投影头带来0.24（PCK_img）和0.06（PCK_bbox）的小幅稳定提升
  • 投影头只在训练阶段增加计算量，推理时可以直接丢弃，不会增加推理开销

5. 结论与局限

5.1 结论

CleanDIFT是一种全新的扩散特征提取范式。它通过轻量微调，将预训练扩散骨干网络中所有时间步对应的差异化特征表示，整合为一套统一的特征表示，最终输出无噪声、不依赖时间步的通用型扩散特征。该方法具有微调成本低，推理极简高效的特点。

5.2 局限性

CleanDIFT的设计目标是提升扩散模型的特征提取质量，服务于下游视觉任务（分割、匹配、深度估计），设计场景聚焦于视觉表征下游应用，暂未覆盖生成类任务等其他扩散模型应用场景。
