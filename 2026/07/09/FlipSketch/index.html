[论文阅读]FlipSketch: Flipping Static Drawings to Text-Guided Sketch Animations

[论文笔记] FlipSketch：将静态草图转化为文本引导的素描动画

paper: FlipSketch: Flipping Static Drawings to Text-Guided Sketch Animations
Subjects: Graphics (cs.GR); Computer Vision and Pattern Recognition (cs.CV)

摘要

素描动画是极具表现力的视觉叙事形式，从简单的翻页涂鸦到专业工作室制作都有广泛应用。传统动画需要专业画师团队绘制关键帧与中间帧，现有自动化方案仍需要创作者指定精确运动路径或关键帧，人力成本依然很高。

本文提出FlipSketch系统，重现翻页动画的创作乐趣——只需画出静态草图，再用文字描述想要的运动效果即可生成动画。该方法利用文本到视频（T2V）扩散模型的运动先验，通过三项核心创新实现素描动画生成：（1）针对素描风格帧生成的微调适配；（2）参考帧机制，通过噪声优化在全流程中保留输入草图的视觉完整性；（3）双注意力合成机制，在实现流畅运动的同时不丢失视觉一致性。

与受约束的矢量动画不同，本文的光栅帧方案支持动态的草图形变，保留了传统手绘动画的表达自由度。最终系统直观易用，让素描动画创作变得像随手涂鸦加文字描述一样简单，同时保留了手绘动画的艺术本质。

1. 研究背景与挑战

1.1 研究背景

素描动画是极具表现力的视觉叙事形式，中间帧绘制是动画制作的核心流程。将静态草图转化为流畅动画，是图形学与AIGC领域的重要研究方向。

1.2 核心难点

将静态草图转化为流畅动画面临三大关键技术挑战：

  1. 调整视频生成模型以保留手绘草图独特的艺术风格，避免生成结果偏向写实照片质感；
  2. 通过在各帧间保持输入草图的视觉完整性来确保时间一致性，避免画面闪烁、走形；
  3. 支持无约束运动，既能实现动态修改又能维持视觉连贯性，突破只能挪动已有笔画的限制。

1.3 本文核心贡献

本文的核心贡献分为三点：

  1. FlipSketch系统：首个通过文本引导从单张手绘草图生成无约束草图动画的系统，灵感来自文本到视频（T2V）扩散模型的运动先验。
  2. 参考帧技术：一种基于迭代噪声优化的新型参考帧技术，可在各帧间保持草图的视觉完整性，设计思路与传统动画原理相似。
  3. 双注意力合成机制：既能实现流畅的运动效果，又能保留草图的独特性，支持超越简单笔触操作的动态变形。

这些技术的结合让草图动画创作变得如同随手涂鸦并加以描述般简单，同时保留了传统动画的表达自由。

2. 相关工作

ModelScope T2V

阿里达摩院2023年开源的17亿参数模型，是最早的开源T2V模型之一。它在Stable Diffusion基础上加入时空模块，默认生成16帧256×256视频。FlipSketch就是在该模型基础上做LoRA轻量微调。

LiveSketch——矢量路线的SOTA

首次提出用T2V运动先验驱动矢量素描动画：把素描表示为贝塞尔曲线笔画，通过分数蒸馏采样（SDS）损失，迭代优化每个笔画控制点的位置，实现文本引导的动画。但是该方案只能挪动已有笔画，不能新增线条。本文旨在光栅素描动画路线，生成像素级素描帧，支持更自由的形变与线条增减。

Inversion for GenAI

图像的生成建模以及图像特征的生成建模，可通过将图像或特征反向映射至其潜在表示中，并寻找编辑方向来实现编辑。本研究采用DDIM反向映射，在文本到视频（T2V）的潜在空间中对输入草图进行反向映射。这一方法有助于我们基于输入草图和文本提示词共同生成视频。

3. 方法架构

FlipSketch把每一帧都当成一张完整的像素画，每一帧都可以重新绘制，线条可以新增、可以消失、可以变形。但有两个核心问题要解决：风格问题和一致性问题。

针对这两个问题，作者设计了三层机制：

  • LoRA微调：为了从文本提示词生成动画，对预训练的ModelScope T2V模型训练了一个LoRA，适配素描风格。
  • 参考帧初始化：把输入素描变成生成的“锚点”，保证第一帧和原图一模一样。
  • 迭代帧对齐 + 双注意力引导：生成过程中不断用锚点校正后面的帧，让它们动起来但不跑偏，解决一致性问题。

3.1 Setup（参考帧初始化）

整个初始化分为三步：

  1. 潜空间压缩：把素描压缩成潜空间特征，例如256×256的像素图，压缩后变成32×32的特征图，计算量降到1/64。
  2. DDIM反转：找到能生成这张画的初始噪点。我们把这个噪点叫做参考噪声，它就是第一帧的种子，并且不给任何文字描述，只用空提示。
  3. 拼接视频初始噪点：视频不止一帧，默认有M帧。第一帧已有，剩下的帧用普通随机噪点就行。最后把它们拼在一起，就得到了整个视频的初始噪点序列。

3.2 Iterative Frame Alignment（迭代帧对齐）

视频模型的时间注意力会让帧与帧互相影响，后面的随机噪点会导致第一帧最后也不像原本的输入。所以在去噪的前半段，每一步都反复微调后面帧的噪点，全程不改模型，不改动第一帧，只调整后面帧的噪点数值。去噪中后期都直接正常去噪。

具体步骤：

  1. 输入当前步第1帧的参考噪点和空文本提示，让模型输出这一帧的去噪指令，记作η1\eta_1η1​，得到第一帧的标准去噪特征。
  2. 输入所有帧的噪点和动作文本提示PinputP_{input}Pinput​（比如“猫在走路”），模型输出每帧的去噪指令。我们只取第一帧的结果，记作η1′\eta_1'η1′​。因为受到了后面随机噪点的干扰，这时候的η1′\eta_1'η1′​和η1\eta_1η1​是不一样的，存在偏差。
  3. 计算偏差，用两个特征的差的平方和当损失，叫「对齐损失」：

    Lalign=∥η1′−η1∥22L_{align} = \|\eta_1' - \eta_1\|_2^2 Lalign​=∥η1′​−η1​∥22​

    模型的时间注意力层，把所有帧的计算连在了一起，形成了一条完整计算链条：后面帧的噪点 → 时间注意力 → 影响第一帧的特征 → 影响损失值。我们通过反向传播改正后面帧的噪点数值，重复迭代，得到优化后的后续帧噪点。

直到当前时间步ttt小于阈值τ1\tau_1τ1​，进入下一步。当前时间步的噪点都优化好了，就正常执行一步去噪，之后进入下一个时间步，重复上面整套操作。

3.3 Guided Denoising with Attention Composition（注意力组合引导去噪）

为防止帧的运动变形，从单帧形状和帧间稳定两个维度同时注入参考帧特征，分为空间自注意力组合和时间自注意力组合两部分。

（a）空间自注意力组合

蓝色部分为参考帧：把二维的特征图拉平再乘投影矩阵得到Q和K；用组合函数CSC^SCS把两部分拼在一起。橙色为生成帧自注意力，绿色为参考交叉注意力。

对混合分数做Softmax归一化，得到注意力权重；用这些权重，把所有位置的V特征按比例加起来，得到最终的输出特征。参考帧的影响权重NNN不是固定的，会随去噪步数线性衰减。该机制在单帧画面的像素位置之间维持稳定，保证草图轮廓、线条细节不丢失。

（b）时间自注意力组合

在帧与帧的时间维度对齐，解决整体画风走形的问题，通过λ\lambdaλ参数控制运动幅度。

每一帧动画都会额外和参考范本算相似度。λ\lambdaλ是给用户可调的超参数，直接作用在蓝色参考帧的K上：

  • λ\lambdaλ越大 → 参考K的数值被放得越大 → 参考帧的影响力越强 → 每帧都极像原图，动作更平缓
  • λ\lambdaλ越小 → 参考帧影响力越弱 → 动画动态更强，但草图相似度会轻微下降

4. 实验结果分析

4.1 定性对比

在多个测试样本上的对比结果：

  • Live-Sketch：草图还原度高，但动作僵硬，无法实现转身、多角度变化，只能挪动已有笔画。
  • SVD/DynamiCrafter：画面糊化，手绘线条消失，偏向照片质感，丢失了素描的艺术风格。
  • FlipSketch：既保留了手绘草图的线条风格，又能实现流畅、大幅度的动态效果，支持物体形变与多角度变化。

    展示的典型案例包括：玩耍的猫、展翅翱翔的鹰、奔跑跳跃的瞪羚、弯腰鞠躬的芭蕾舞者等，均能实现符合文本描述的流畅动画。

4.2 定量指标与消融实验


基于CLIP的指标对比显示，本文方法在S2V一致性和T2V对齐度上均取得均衡表现。

消融实验包含三组变量：

  1. 可调超参数λ\lambdaλ：λ=1\lambda=1λ=1时草图一致性最高，但动作幅度受限；λ=0\lambda=0λ=0时动画动态更强，但草图相似度轻微下降。用户可根据需求自由调节。
  2. 移除时空注意力CTC_TCT​、CSC_SCS​：S2V一致性会大幅下跌，证明双注意力是维持草图线条、轮廓的核心机制。
  3. 移除迭代帧对齐：草图一致性小幅下降，证明噪声迭代优化能稳定动画早期画面，防止第一帧跑偏。

用户研究结果显示，本文方法在一致性、保真度和主观MOS评分上均优于基线方法；移除双注意力模块后各项评分均有明显下降，验证了该模块的关键作用。

4.3 拓展应用

本文框架具备良好的拓展能力：对比本文和Dynamic Typography（矢量文字动效方案）的文字变形表现力，FlipSketch能实现更丰富的文字形变效果。

下游应用场景：可以用素描动画当骨架，辅助生成真实感视频，结合近期基于扩散的视频编辑和视频生成空间控制技术，拓展到真实世界视频生成场景。

5. 结论与局限

5.1 结论

本文提出无约束栅格草图动画方案FlipSketch，得益于T2V扩散模型的大规模预训练，栅格动画具有丰富的动态性，同时能保留草图的艺术特征。该方法在动态范围和动画质量上均优于当前最优的矢量草图动画方案。最后，研究结合近期基于扩散的视频编辑和视频生成空间控制技术，探索了本研究在真实世界视频生成中的应用潜力。

5.2 局限性

  1. 由于训练数据在风格上是单模态的，生成的视频在风格上与CLIPasso的草图略有相似之处，风格多样性有限。
  2. 流程对草图抽象的处理效果不佳，需要高质量且几何精度准确的插画作为输入。抽象输入和不规则几何形状往往会导致草图与视频的关联性较差。
  3. 模型运动能力完全依托底座ModelScope T2V预训练阶段学到的运动先验，生成动画时常出现多余肢体、物体几何结构错乱等失真问题。
