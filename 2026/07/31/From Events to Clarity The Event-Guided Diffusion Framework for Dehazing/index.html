[论文笔记] EvDehaze：事件引导的扩散模型去雾框架

paper: From Events to Clarity: The Event-Guided Diffusion Framework for Dehazing
Subjects: Computer Vision and Pattern Recognition (cs.CV)

摘要

雾霾环境下的清晰成像是一项关键任务。基于先验与基于神经网络的方法都已取得一定进展，但这类方法均基于RGB帧进行处理，受限于有限的动态范围，去雾结果往往存在结构丢失、光照细节缺失等问题。为解决这一问题，本文首次将事件相机应用于图像去雾任务。事件相机具备更高的动态范围（120dB vs 60dB）与微秒级延迟，天然适配雾霾场景。

在实际应用中，将事件中的高动态范围线索迁移到RGB帧中存在难度，因为真实场景下的成对标注数据十分稀缺。针对该问题，本文提出事件引导扩散模型，利用扩散模型强大的生成先验，有效迁移事件中的高动态信息，从有雾输入中重建清晰图像。具体而言，本文设计了事件多尺度金字塔表征，将边缘、角点等结构化信息注入扩散潜空间，为生成过程提供精准的结构引导，提升视觉真实感并减少语义偏移。

为验证真实场景下的效果，本文采集了重度雾霾（AQI=341）环境下的无人机数据集，包含同步的RGB与事件传感器数据。在两个基准数据集与自采数据集上的实验均达到了当前最优水平。

1. 研究背景与挑战

1.1 研究背景

雾霾会通过光线散射与吸收大幅压缩成像的动态范围，导致图像纹理、边缘细节严重丢失，既降低视觉质量，也影响无人机巡检、自动驾驶等下游视觉任务的有效性，因此雾天清晰成像具有重要的应用价值。

与传统相机相比，事件相机的成像原理完全不同：它不是逐帧记录完整场景，而是记录场景的亮度变化。对于单个像素点，只有接收的光强产生变化并超过阈值时，该像素点才会输出信号——亮度增加输出正事件（+1），亮度降低输出负事件（-1）。输出可看作一维二值信号，每个信号点包含(x, y, t, p)四元信息，即横向纵向坐标、时间戳、事件极性（±1）。在静止场景下，事件相机几乎没有有效输出。

1.2 核心难点

事件相机的高动态范围特性，使其在雾霾环境下依然能保留精准的边缘、轮廓与光照变化信息，理论上可以为RGB图像去雾提供关键的结构线索，弥补普通RGB传感器的信息缺失。

但在真实场景中，雾霾浓度、光照条件完全不可控，几乎无法采集到严格对齐的有雾图像-清晰图像成对标注数据；而传统事件引导的增强方法大多依赖大规模成对数据集学习映射关系，无法直接套用在去雾任务上。

因此本文的核心问题是：在缺少真实成对标注数据集监督的前提下，如何将事件的高动态范围信息有效注入去雾模型，提升真实浓雾场景下去雾结果的结构准确性与视觉真实感。

1.3 本文目标

首次提出事件引导的图像去雾任务，并将其建模为扩散模型框架下的条件图像生成问题，为事件辅助去雾提供了全新的技术路线。

2. 相关工作

（1）基于帧的图像去雾方法

传统方法依赖大气散射模型，代表方法有DCP等。这类方法具备物理可解释性，但在复杂真实场景中泛化能力较差。

深度学习方法以DehazeNet、PMHLD、传输传播网络为代表，部分方案完全脱离物理模型，采用端到端监督学习实现去雾。这类方法效果提升显著，但高度依赖大规模合成成对数据集，真实场景下表现受限。

后续发展出无监督去雾方法，无需成对标注数据即可训练。但所有帧去雾方法都仅依赖RGB图像输入，受限于传感器有限的动态范围，在动态复杂场景下存在本质瓶颈。

（2）基于事件的图像增强方法

事件相机已在图像重建类任务中展现出突出潜力，覆盖视频插帧、图像去模糊、卷帘校正、HDR成像等多个方向，能够克服传统相机在极端成像条件下的缺陷。

除此之外，事件也被用于缓解环境退化带来的画质问题，例如去雨、去雪，代表工作有事件引导视频去雨框架、异构去雨网络等。

（3）扩散模型相关方法

扩散模型也已被应用于真实场景图像复原，验证了其实用价值。

3. 方法架构

EvDehaze是首个事件引导的潜空间扩散去雾框架，输入为单张有雾RGB图像与同步采集的事件流数据E，输出为去雾后的清晰RGB图像。

框架由三大核心组件构成：

  • 带冻结VQ-VAE的DDIM扩散主干：负责图像的潜空间编解码与迭代去噪生成
  • 事件表征模型：将稀疏事件流转换为多尺度结构化特征
  • 事件引导扩散模块：通过交叉注意力将事件特征注入每一步去噪过程

模块1：带潜空间VQ-VAE的DDIM主干

在低维隐空间中完成扩散生成，降低计算量，同时利用预训练VQ-VAE的通用图像先验稳定生成质量。有雾图像经VAE编码器压缩为潜变量，在潜空间中完成多步迭代去噪，最终经VAE解码器还原为清晰RGB图像。

模块2：事件表征模型


将原始事件流转换为和图像空间对齐的特征图，为扩散模型提供结构引导。事件相机输出的原始事件流E，是一长串零散的亮度变化点，每个点包含像素坐标x,y、时间戳t、极性p四类信息。

步骤1：时间金字塔表征（TPR）

搭建3层时间金字塔，把同一段事件流按大、中、小三种时间窗口切成3层：

  • 第1层（粗尺度）：时间窗口最大，覆盖慢运动、远处物体的完整边缘
  • 第2层（中尺度）：时间窗口中等，兼顾普通速度的运动
  • 第3层（细尺度）：时间窗口最小，捕捉快运动、近处物体的精细边缘

每层内分2个时间仓，每一层的时间窗口再平均切成2小段，如窗口总长0.1秒，就切成「0~0.05秒」和「0.05~0.1秒」两个仓。把3层、每层2张图拼在一起，就得到一个多维的立体网格。

最终得到TPR表征ETPRE_{TPR}ETPR​，形状为3层×2仓×256×2563 \text{层} \times 2 \text{仓} \times 256 \times 2563层×2仓×256×256。实际送入网络时，会把“层数+时间仓”展平成通道维度，变成6通道、256×256的特征图，与普通图片格式一致。

输入与输出

  • 输入：原始事件流E（一堆零散的(x,y,t,p)事件点）
  • 输出：事件时间金字塔表征ETPRE_{TPR}ETPR​（规整的4维张量，展平后是6×256×256的多通道特征图）

设计原因

  • 解决稀疏问题：把零散的点累积成网格，神经网络才能处理
  • 多尺度适配：慢运动、远物体用大窗口拍全轮廓；快运动、近物体用小窗口不拖影，场景适配性更强
  • 保留时间信息：分仓设计保留了亮度变化的先后顺序，比“全堆成一张图”特征更丰富

步骤2：卷积特征提炼

使用3层卷积+池化操作，对TPR表征进一步提炼，得到更紧凑的多尺度结构特征图，同时缩小特征尺寸，适配扩散U-Net的不同层级输入。

模块3：事件引导扩散模块

通过交叉注意力机制，将事件特征注入扩散U-Net的每一步去噪过程。

  • U-Net当前步的中间特征作为键K和值V
  • 编码后的事件特征作为查询Q

该交叉注意力模块被嵌入到U-Net的多个中间层中，且在每一步DDIM去噪时都会生效，为生成过程提供持续的结构约束，引导模型还原准确的边缘与纹理细节。

训练损失函数

总损失由两部分构成：

  1. L1像素损失：计算生成图像与真实清晰图像的逐像素绝对值差
  2. 感知损失：计算输入和目标图像在VGG特征图上的差异

真实数据集采集

基于大疆Matrice 300 RTK无人机搭建采集系统，搭载PROPHESEE EVK4 HD事件相机与Intel RealSense D435i RGB相机，在广州重度沙尘雾霾天气（AQI=314）下，于80-120米高度飞行采集，共获取30分钟同步数据，用于真实场景下的算法验证。

4. 实验结果分析

4.1 定量对比

在SOTS合成数据集与NH-HAZE真实雾天数据集上与多种去雾方法对比，涵盖传统方法、深度学习方法与扩散类方法。实验结果显示，EvDehaze在两项数据集上均取得了具有竞争力的指标，在真实雾天场景下优势更为明显，超越了同类型的扩散基线方法。

4.2 定性对比

在合成测试样本上，其余方法存在残留雾气、过度平滑纹理、色彩偏移等问题；EvDehaze可以还原窗户百叶、路灯、细树枝等高频精细结构，对比度自然，残留雾更少，视觉效果最贴近真值。

(a)©为带事件热力图叠加的原始浓雾输入；(b)(d)为EvDehaze去雾输出。可以看到大面积浓雾被有效去除，远处建筑、道路标线、球场纹理完整恢复。右侧亮度直方图显示，输出图像亮度区间更广，中高亮度信息更丰富，证明模型有效拓展了图像动态范围，贴合论文理论推导。

4.3 消融实验

架构消融

四组对照实验验证各模块的作用：

  1. Baseline ResShift：无事件、无交叉注意力的纯扩散基线
  2. w/o event data：去掉事件输入，指标大幅下跌，证明事件信息的核心作用
  3. w/o cross attention：保留事件，去掉交叉注意力，仅采用特征拼接，效果弱于完整模型
  4. Full EvDehaze：完整模型，取得最优指标

采样器消融

对比不同扩散采样器与采样步数的效果，同等15步下DDIM指标优于DDPM，因此最终方案采用DDIM采样器。

4.4 事件特征可视化

热力图高亮区域集中在物体边缘、角点、纹理交界位置，即使在浓雾场景下结构线索依然稳定，证明事件特征能为扩散采样提供可靠的结构先验。

4.5 去噪过程可视化

展示从Step 0到Step 15的完整去噪过程，图像逐步从噪声状态恢复为清晰的去雾结果，最终效果与真值高度接近。

4.6 仿真事件验证

展示缩放、旋转、平移等多种运动下生成的仿真事件。事件仅在物体边界、纹理变化处产生响应，静态区域无事件，证明Vid2E生成的仿真事件能精准捕捉结构轮廓，可用于模型训练。

5. 结论与局限

5.1 结论

本文提出了EvDehaze，这是首个适用于真实场景下图像去雾的事件引导扩散框架。通过利用事件相机的高动态范围和时间保真度，模型通过交叉注意力机制在潜在扩散过程中注入细粒度的结构线索。

在合成数据集和真实世界数据集上的大量实验不仅证明了EvDehaze在基于扩散的方法中具有优越性，还验证了事件引导本身的实际有效性。在Restormer+EGDM和EvDehaze两种模型中，添加事件线索均能持续提升恢复质量，这表明事件是有效的强结构先验。

5.2 局限性

当前的一个局限性是依赖固定的VQ-VAE骨干网络，这可能会限制其在高动态场景中的适应性。VQ-VAE是在普通清晰日常图片上预训练的，对极端雾天场景的潜空间表征能力存在一定上限。
