[论文笔记] CaricHarmony：免训练的漫画肖像生成中身份-形状冲突协调

paper: CaricHarmony
Subjects: Computer Vision and Pattern Recognition (cs.CV)

摘要


漫画肖像（Caricature）生成要求模型同时满足两个看似矛盾的目标：保留人物的身份特征（保真），同时按照手绘草图进行形状夸张（夸张）。本文提出 CaricHarmony，一种免训练的漫画肖像合成框架，通过设计作用于扩散中间特征的专用对齐机制，显式处理身份-形状冲突，实现保真与夸张的动态平衡。该方法的核心思路是构建两条对比路径——纯身份路径和融合主路径，并设计定制化的能量函数，为模型提供关于偏离身份或形状条件程度的额外信息，通过梯度引导修正去噪方向，推动模型在协调二者之间达成平衡。实验表明，CaricHarmony 不仅可以保持高身份保真度，还能保留手绘草图所定义的形状夸张效果，在多项指标上显著优于现有方法。

1. 研究背景与挑战

1.1 研究动机

漫画肖像生成是计算机视觉与图形学交叉领域的一个重要研究方向，其目标是根据输入的人物照片和夸张草图，生成既保留人物身份特征、又符合草图所定义夸张形状的漫画风格肖像。这一任务在娱乐应用、数字艺术创作、个性化头像生成等场景中具有广泛需求。

1.2 核心难点

漫画肖像生成面临的核心挑战在于保真与夸张之间的内在冲突。从扩散模型的概率视角来看，在去噪空间内，身份区域和形状区域的概率密度远高于中间平衡区域——也就是说，模型在去噪过程中天然倾向于要么完全偏向身份保真（忽略夸张形状），要么完全偏向形状跟随（丢失身份特征），而两者之间的平衡点极难达到。

具体而言，这一冲突体现在：

  • 当模型过度关注身份条件时，生成的图像虽然保留了人物特征，但忽略了草图中定义的夸张变形；
  • 当模型过度关注形状条件时，生成的图像虽然符合草图轮廓，但人物身份特征严重丢失；
  • 两者之间的平衡区域在概率空间中占比极小，模型难以自发找到。

1.3 本文贡献

针对上述挑战，本文的核心贡献为：

  • 设计了作用于扩散中间特征的专用对齐机制，构建一套完全免训练的方案，无需对预训练扩散模型进行任何微调或额外训练。
  • 通过双路径对比和能量函数引导，实现身份保留和形状夸张的动态可控调节。

2. 相关工作

2.1 现有漫画生成方法的不足

现有漫画肖像生成方法存在以下局限：

  1. 早期 GAN 类方法：仅在输入条件上无格式限制，但生成质量有限，且难以同时兼顾身份保真和形状夸张。
  2. DemoCaricature：每个新身份都需要约 70 秒的逐样本微调，无法实现即时生成，实用性受限。
  3. CaricatureBooth：不免训练，需要针对特定数据集进行模型训练，泛化能力有限。

2.2 免训练身份注入方案

IP-Adapter 与 PuLID 是两种典型的免训练人脸身份注入方案：

  • IP-Adapter：通过新增交叉注意力层，将身份特征转化为键值矩阵，和文本条件并行注入扩散模型，实现免训练的身份保持生成。
  • PuLID：在 IP-Adapter 的基础上结合对比对齐机制，进一步提升身份特征的注入精度和保真度。

2.3 空间条件控制

T2I Adapter 是一个即插即用的空间条件控制工具，能够将草图、边缘图、深度图这类空间条件编码成多尺度特征，直接叠加到 UNet 编码器的对应层级，实现对生成图像的精准空间控制。

本文方法正是建立在上述免训练身份注入和空间条件控制的基础之上，通过创新的对齐机制将两者有机融合。

3. 方法架构

3.1 双路径设计

CaricHarmony 的核心设计是构建两条对比路径，分别代表"纯身份"和"身份+形状融合"两种生成模式：

  • 纯身份路径 PiP^iPi：仅输入身份条件 CidC_{id}Cid​ + 文本提示 CtxtC_{txt}Ctxt​，不输入形状条件。该路径代表"完全保真、不做夸张"的生成方向。
  • 融合主路径 Pi+sP^{i+s}Pi+s：同时输入 Cid+Cs+CtxtC_{id} + C_s + C_{txt}Cid​+Cs​+Ctxt​ 三类条件（身份条件、形状条件、文本条件）。该路径是实际生成图像的主路径，需要同时兼顾身份和形状。

3.2 激活区间设计

为了在去噪过程的不同阶段分别侧重形状和身份的引导，论文设计了时间步相关的激活区间：

  • 形状引导激活区间：t∈[1000,700]t \in [1000, 700]t∈[1000,700]，即在去噪早期（噪声较大时）侧重形状对齐，因为此阶段主要决定图像的全局结构和布局。
  • 身份引导激活区间：t∈[900,400]t \in [900, 400]t∈[900,400]，即在去噪中后期侧重身份对齐，因为此阶段主要决定图像的细节纹理和身份特征。

关键规则：不在激活区间时，对应能量项为 0，不提供梯度引导。这确保了每种引导只在最合适的时间步发挥作用，避免相互干扰。

3.3 融合主路径前向过程

融合主路径的执行流程如下：

  1. 用 UNet 去噪网络分别计算带条件的噪声预测和不带条件的噪声预测（用于 CFG）。
  2. 缓存这一步 UNet 内部的查询 QQQ、文本键 KKK、身份注意力输出 OOO，供后续能量计算使用。
  3. 第二步输入形状 + 文本条件，执行一步 DDIM 采样；输出形状路径下一步隐变量和形状路径的查询矩阵 QQQ。

3.4 形状能量计算

形状能量 ElayoutE_{\text{layout}}Elayout​ 的计算方式为：按形状和主路径网格位置计算加权 L2 距离，其中笔画区域权重更高。这意味着模型在草图笔画经过的区域会受到更强的形状约束，确保夸张轮廓被准确遵循。

此外，还引入语义一致性约束：对比两条路径下查询特征对文本键的注意力分布差异，确保形状引导不会破坏文本语义的一致性。

3.5 纯身份路径前向采样

纯身份路径的执行流程为：

  1. 身份经 PuLID 编码器提取身份条件，结合文本条件，执行一步带 CFG 的 DDIM 采样，完成一次去噪更新。
  2. 得到身份路径的交叉注意力查询矩阵 QiQ^iQi、身份注意力输出 OiO^iOi。

3.6 身份能量计算

身份能量的计算采用语义匹配 + 特征对齐的策略：

  1. 对主路径每个查询 qjq_jqj​，在 QiQ^iQi 中通过余弦相似度检索出语义最匹配的 qkiq_k^iqki​。
  2. 计算主路径输出 ojo_joj​ 与对应身份输出 okio_k^ioki​ 的加权 L2 距离，作为身份能量。

这一设计确保了主路径在语义对应的位置上尽可能保留身份特征，而非简单地进行全局对齐。

3.7 梯度引导与迭代修正

将身份能量和形状能量的梯度乘以引导强度 η\etaη，叠加到基础噪声预测上，修正去噪方向：

ϵ^=ϵbase+ηs∇Elayout+ηi∇Eidentity\hat{\epsilon} = \epsilon_{\text{base}} + \eta_s \nabla E_{\text{layout}} + \eta_i \nabla E_{\text{identity}} ϵ^=ϵbase​+ηs​∇Elayout​+ηi​∇Eidentity​

整个对齐过程遵循"对齐 → 算能量 → 修正 → 更新"的循环，在每个时间步迭代 NNN 次，逐步将生成结果拉向身份与形状的平衡点。

4. 实验结果分析

4.0 部分结果展示

4.1 能量权重调节

论文通过调整两类能量（身份能量和形状能量）的权重系数，验证了模型对保真-夸张平衡的可控性。增大身份能量权重时，生成结果更偏向保真；增大形状能量权重时，生成结果更偏向夸张。用户可根据需求灵活调节。

4.2 不同夸张程度的草图

论文还测试了使用不同夸张程度的草图作为形状条件时的生成效果。结果表明，无论草图的夸张程度如何，CaricHarmony 都能在保持身份可识别性的前提下，准确跟随草图定义的形状变形。

5. 结论

我们提出了一种 caricature 合成模型，通过显式处理身份-形状冲突实现了显著的性能提升。该方法的核心是一个无需训练的框架，它将交叉注意力机制中的隐藏特征与两条对比路径的特征进行对齐，从而实现对身份保留和形状夸张的动态控制。我们设计了定制化的能量函数，为模型提供关于偏离身份或形状条件程度的额外信息，推动模型在协调二者之间达成平衡。该方法不仅可以保持高身份保真度，还能保留手绘草图所定义的形状夸张效果，为漫画肖像生成提供了一种高效、灵活、免训练的全新解决方案。
